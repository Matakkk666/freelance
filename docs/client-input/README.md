# Исходные материалы заказчика

Здесь лежат тексты заказчика **без изменений**: ТЗ, дополнения, ответы на вопросы, переписка,
расшифровки созвонов. Это первоисточник. Нормализованные требования — в
[../requirements.md](../requirements.md), решения — в [../decisions.md](../decisions.md).

## Правила

- Один документ — один файл `YYYY-MM-DD-<slug>.md`, например `2026-10-05-tariffs-answers.md`.
- Файлы не редактируются задним числом. Уточнение от заказчика — это новый файл.
- Персональные данные людей (телефоны, личные email, документы), ключи, пароли и токены
  сюда не кладём. Заменяй их на `[удалено]`. Ключи передаются только через env (M8).
- Вложения (PDF, макеты, таблицы) кладутся рядом с тем же префиксом:
  `2026-10-05-tariffs.pdf`.

## Шаблон

```markdown
# <Краткое название>

- Дата: YYYY-MM-DD
- От кого: заказчик / владелец проекта (пересказ заказчика)
- Канал: чат / почта / созвон / документ
- Обработано: <ссылка на PR> (заполняется при внесении в requirements.md)

## Текст

<текст как есть>
```
