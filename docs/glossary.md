# Глоссарий (RU → EN)

Используй эти имена в коде, API и БД. Если термина нет, добавь его сюда в том же PR.

| Русский | В коде | Значение |
|---|---|---|
| баланс | `balance` | сумма на счёте. «Баланс пользователя» — баланс счёта `available` |
| счёт | `account` | учётная единица ledger (пользовательский или системный) |
| доступный баланс | `available` | вид пользовательского счёта |
| зарезервировано | `reserved` | вид пользовательского счёта под незавершённые покупки |
| операция (ledger) | `ledger_transaction` | набор проводок с нулевой суммой |
| проводка | `ledger_entry` | изменение одного счёта на сумму `amount` (+/−) |
| резерв | `hold` | перевод `available → reserved` |
| списание | `capture` | окончательное списание из `reserved` |
| снятие резерва | `release` | возврат `reserved → available` |
| сторно | `reversal` | обратная операция для исправления ошибки |
| корректировка | `adjustment` | ручное изменение баланса админом через ledger |
| ключ идемпотентности | `idempotency_key` | уникальный ключ, защищающий от повторов |
| пополнение | `deposit` | поступление средств через криптопроцессинг |
| вывод | `withdrawal` | вывод средств (не на этапе 1) |
| криптопроцессинг | `processing` | провайдер приёма криптоплатежей |
| партнёр, поставщик | `partner`, `provider` | внешний сервис; `provider` — значение переменной `<SERVICE>_PROVIDER` |
| адаптер | `adapter`, `client` | код интеграции с партнёром |
| заказ | `order` | покупка продукта партнёра |
| сверка | `reconciliation` (`reconcile`) | выяснение итогового статуса у партнёра |
| в обработке | `processing` (статус заказа) | исход у партнёра неизвестен, ждём сверки |
| продукт, товар | `product` | eSIM, подарочная карта и т. п. |
| подарочная карта | `gift_card` (модуль `giftcards`) | |
| криптокарта | `card` (модуль `cards`) | банковская карта от поставщика криптокарт |
| тариф | `plan` | Стандарт (`standard`), Plus (`plus`), Premium (`premium`) |
| функция тарифа | `plan_feature`, `feature_key` | возможность или лимит тарифа |
| права по тарифу | `entitlements` | вычисленный набор функций пользователя |
| подписка | `subscription` | |
| продление | `renewal` | |
| комиссия | `fee` | |
| правило комиссии | `fee_rule` | |
| реферальная программа | `referral program` (модуль `referrals`) | |
| реферальный код | `referral_code` | |
| пригласивший | `referrer` | |
| приглашённый | `referred_user` | |
| реферальное вознаграждение | `referral_reward` | |
| правило рефералки | `referral_rule` | |
| журнал аудита | `audit_log` | |
| администратор | `admin` (роль) | |
| фоновая задача | `job` | |
| воркер | `worker` | процесс, выполняющий фоновые задачи |
| вебхук | `webhook`, `webhook_event` | входящее уведомление партнёра |
| ПДн | `pii` | персональные данные |
