# Документация партнёров

Единственный источник правды об API внешних сервисов. Реальный клиент адаптера пишется
**только** по документации из этой папки. Без неё — только интерфейс и мок
(см. [AGENTS.md](../../AGENTS.md#интеграции-с-партнёрами)).

## Структура

```
docs/partners/<partner-slug>/
  NOTES.md        выжимка для разработки (шаблон ниже), пишет агент или разработчик
  original/       документация партнёра как есть: PDF, HTML, OpenAPI, примеры, письма
```

Ключи и секреты сюда не кладём. Только в env (M8).

## Шаблон NOTES.md

```markdown
# <Партнёр> (<сервис>)

- Источник: original/<файл>, версия/дата документации
- Окружения: sandbox URL, production URL
- Аутентификация: тип (API key / HMAC / OAuth), заголовки. Имена переменных env
- Идемпотентность: поддерживается ли, как передаётся ключ
- Операции, которые нам нужны: метод, путь, ключевые поля запроса и ответа, ссылка на раздел
- Статусы и их соответствие нашим (completed / failed / processing)
- Ошибки: коды, какие считать отказом, какие — неизвестным исходом
- Webhook: события, формат, подпись (алгоритм, заголовок, timestamp), повторы
- Лимиты: rate limit, таймауты, минимальные и максимальные суммы
- Деньги: валюта, точность, формат сумм (строка или число)
- Открытые вопросы к партнёру
```
