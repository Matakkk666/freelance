# Решения и открытые вопросы

Журнал архитектурных решений. Новое решение добавляется в конец с очередным номером.
Решение не удаляется: если оно меняется, старому ставится статус «заменено D-0NN».

Статусы: **принято** — действует; **предложено** — принято по умолчанию агентом, владелец
может пересмотреть; **заменено** — больше не действует.
